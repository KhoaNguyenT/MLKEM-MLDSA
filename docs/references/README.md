# Reference library

- `papers/` contains standards and papers supplied by the project owner.
- `PAPERS_NEEDED.md` is the acquisition checklist.
- `PAPER_INVENTORY.md` classifies files currently present and records verification status.
- Third-party source repositories are cloned under `Vendor/`, not copied here.

The normative algorithm sources are FIPS 203 and FIPS 204. Architecture papers and
legacy Kyber/Dilithium implementations are research inputs, not final specification.
